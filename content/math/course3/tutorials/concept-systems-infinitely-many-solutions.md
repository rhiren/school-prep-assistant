# Systems with Infinitely Many Solutions

## One line, two descriptions

Consider `x + y = 6` and `2x + 2y = 12`. Doubling every term in the first equation produces the second. The rules look different, but describe exactly the same line.

Every point on that line satisfies both equations. There are infinitely many such points: `(0, 6)`, `(1, 5)`, `(2.5, 3.5)`, and many more. This does not mean every point in the plane works. For example, `(0, 0)` fails both rules.

## Recognizing an identity

Multiply the first equation by 2 and subtract the second:

`(2x + 2y) - (2x + 2y) = 12 - 12`

`0 = 0`

This true statement means the second rule adds no new restriction. Keep the original condition `x + y = 6` when describing the solutions. Do not report `x = 0` or `y = 0` just because the variables canceled.

## Compare with no solution

Change the second equation to `2x + 2y = 14`. Now subtraction gives `0 = 2`, which is false. These are distinct parallel lines, so no ordered pair satisfies both.

| Graph relationship | Algebra clue | Solution count |
| --- | --- | --- |
| Same line | Both sides reduce to an identity | Infinitely many |
| Distinct parallel lines | Contradiction such as `0 = 2` | None |
| Lines crossing once | One x-value and one y-value | One |

## Missing coefficients

For `3x + y = 7` and `ax + 4y = b` to describe the same line, the multiplier must be 4. Therefore `a = 12` and `b = 28`. Scaling only the coefficients but leaving the constant unchanged would make a different equation.

## Context can narrow the possibilities

If x and y count tickets, `x + y = 6` allows only seven nonnegative integer pairs. The equations have infinitely many real solutions, but the situation excludes negative and fractional ticket counts.

## Try and explain

Does one shared point prove two lines are the same? No: `y = x + 2` and `y = 3x + 2` share `(0, 2)` but have different slopes. Compare the entire equations, not just one example point.
