# Linear Equations Checkpoint

## Big Idea

This checkpoint reviews solving and interpreting linear equations in one variable before moving to systems in Unit 4. The same balance rule appears in every problem, but different equations require different first moves.

## What To Review

- Combine like terms before solving.
- Distribute before moving terms when parentheses appear.
- Move variable terms to one side when variables appear on both sides.
- Clear fractions or decimals when they make the equation hard to read.
- Define the variable before writing an equation from a context.
- Check answers in the original equation.

## Choosing A First Move

| If you see... | First think about... |
| --- | --- |
| Parentheses | distributing carefully |
| Fractions | multiplying by a common denominator |
| Variables on both sides | collecting variable terms |
| A story problem | defining the variable |
| A proposed answer | substituting to check |
| Variables disappear | deciding solution type |

## Worked Review Example

Solve: `2(x + 3) = x + 14`

Distribute:

`2x + 6 = x + 14`

Subtract `x`:

`x + 6 = 14`

Subtract 6:

`x = 8`

Check:

`2(8 + 3) = 22` and `8 + 14 = 22`

## Common Mistake

Do not use the same first step for every equation. Let the structure of the equation tell you what to do first.

## Quick Self-Check

Before solving, say what type of equation it is. After solving, say what the answer means and verify it in the original problem.
