# Compare Functions in Different Representations

## Decide what you are comparing

Two functions can be shown differently yet describe the same kind of quantity. Before calculating, ask whether you need the **rate of change**, the **initial value**, or the **output at a particular input**. These are different comparisons.

Always match units. A cost per hour cannot be compared directly with a total cost or a cost per minute.

## Translate each representation

| Representation of a linear function | Find the rate | Find the initial value |
| --- | --- | --- |
| Equation y = mx + b | Read m | Read b |
| Table | Change in y divided by change in x | Read the row at x = 0, or work backward |
| Graph | Rise divided by run using axis labels | Read the height where x = 0 |
| Story | Change per one input unit | Amount before any input units accumulate |

In a table, a jump from input 2 to input 5 is a run of 3, not 1. On a graph, count actual units from the axis labels, not just squares.

## Worked comparison: table versus equation

Function A is y = 2x + 6. Function B is stated to be linear and has this table:

| Input x | B's output |
| --- | --- |
| 0 | 2 |
| 2 | 8 |
| 4 | 14 |

A has rate 2 and initial value 6. For B, the output rises 6 over an input increase of 2, so the rate is 6 / 2 = 3. B's initial value is 2. Thus A starts higher, but B increases faster.

![Function A, y = 2x + 6, starts above B, y = 3x + 2. The lines meet at (4, 14); B is higher after input 4.](content/math/course3/images/functions-compare-lines.svg)

At input 2, A gives 2(2) + 6 = 10 while B gives 8. A still has the greater output. At input 4, both give 14. At input 5, A gives 16 and B gives 17. A greater rate does not mean a greater output at every input.

## Find a missing starting value

Suppose a straight graph passes through (2, 11) and (5, 20). Its rate is (20 - 11) / (5 - 2) = 9 / 3 = 3. Moving back from input 2 to input 0 decreases the output by 2 times 3, so the initial value is 11 - 6 = 5. The function is y = 3x + 5.

Never use the first listed output as the initial value unless its input is zero.

## Negative rates and different scales

A tank losing 3 liters per minute has rate -3. Another losing 2 liters per minute has rate -2. The second has the greater signed rate because -2 > -3, although the first tank empties faster. Pay attention to the exact wording.

Two graphs drawn with different axis scales may look differently steep even with equal rates. Calculate rise divided by run in the same units before deciding.

## Know what the evidence supports

Two linear functions with equal slopes and equal initial values are the same function. But two matching points alone do not prove two unknown functions are identical. A curved function can pass through those same points. Use the statement that a function is linear; do not silently assume it.

## Apply and explain

1. A is y = 4x + 1. A linear table for B contains (0, 7), (2, 13). Which has the greater rate?
2. Which has the greater output at x = 2?
3. At what input are the outputs equal?
4. For whole-number inputs, what is the first input where A is greater?

## Check the reasoning

1. A has rate 4. B has rate (13 - 7) / 2 = 3, so A increases faster.
2. A gives 9; B gives 13. B is greater at this input.
3. Solve 4x + 1 = 3x + 7 to get x = 6. Both outputs are 25.
4. A is greater when x > 6, so the first whole-number input is 7. Equality at 6 is not enough.
