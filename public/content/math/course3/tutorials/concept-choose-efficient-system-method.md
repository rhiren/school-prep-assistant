# Choose an Efficient System-Solving Method

## Let the equations guide your first move

Graphing, substitution, and elimination describe the same shared solutions. A useful method makes the structure easy to see and keeps arithmetic manageable. More than one method may be valid; convenience is not a rule that makes other methods wrong.

## Use an isolated variable

For `y = 2x + 1` and `3x + y = 16`, substitute the whole expression for y:

`3x + (2x + 1) = 16`

`5x = 15`, so `x = 3` and `y = 7`.

The pair `(3, 7)` satisfies both original equations. Parentheses help protect the substituted expression when a coefficient or minus sign is outside it.

## Look for cancellation

For `2x + 3y = 18` and `-2x + 5y = 14`, add to eliminate x. This gives `8y = 32`, so `y = 4` and `x = 3`.

If coefficients match instead of being opposites, subtract. If nothing cancels, scale entire equations first. For coefficients 2 and 3, the smallest positive common multiple is 6: multiply the equations by 3 and 2 respectively, then subtract matching terms.

## Decide what precision is needed

A graph shows whether lines intersect, overlap, or run parallel. It can estimate an intersection, but a point read near `(1.4, 2.7)` is not automatically exact. Use algebra and substitute back when an exact answer is required.

## Stop and interpret when variables disappear

An identity such as `0 = 0` signals equivalent nondegenerate line equations. A contradiction such as `0 = 5` signals no shared solution. Neither result says the ordered pair is `(0, 0)`.

## Choose, solve, check

| Structure | Efficient starting idea |
| --- | --- |
| A variable is isolated | Substitute its expression |
| Opposite coefficients | Add equations |
| Matching coefficients | Subtract equations |
| Proportional coefficients | Compare constants or eliminate |

Try `x = 2y + 1` and `3x - y = 13`. Substitution gives `5y + 3 = 13`, so `(x, y) = (5, 2)`. Check: `5 = 2(2) + 1` and `3(5) - 2 = 13`.
