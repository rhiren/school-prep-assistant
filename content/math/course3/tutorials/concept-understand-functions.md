# Understand Functions

## One input, one output

A function assigns exactly one output to every allowed input. Think of a student's ID number as an input and their assigned homeroom as the output. Two students can share a room. But one ID cannot identify two different assigned homerooms under that same assignment rule.

The allowed inputs are called the **domain**. Inputs and outputs do not have to be numbers.

![Two different inputs share output 7, while each input has exactly one arrow.](content/math/course3/images/function-shared-output.svg)

## Read a rule forward

Suppose the rule is: multiply the input by 2, then add 1. For input 4, multiply first: 2 times 4 is 8. Add 1 to get output 9. We write the pair (4, 9), with the input first.

| Input x | Calculation | Output y |
| --- | --- | --- |
| 0 | 2 times 0 + 1 | 1 |
| 4 | 2 times 4 + 1 | 9 |
| 6 | 2 times 6 + 1 | 13 |

To work backward from output 13, undo the addition first: 13 - 1 = 12. Then undo multiplication: 12 / 2 = 6. Check by applying the original rule to 6.

## What actually breaks the rule?

Compare (2, 7), (5, 7) with (2, 7), (2, 9). The first relation is a function: each input has one output, even though 7 repeats. The second is not: input 2 has two different outputs.

Repeated identical records such as (2, 7), (2, 7) do not create a conflict. There is still only one distinct output for input 2. A constant rule, such as every input giving 0, also defines a function.

## Look carefully at the input

A day can have different temperatures at noon and at 3 p.m. If the input is just the day, those readings conflict. If the input includes both the day and the time, each measurement can have a unique input. Defining the input precisely matters.

Two instructions do not automatically mean two outputs. A rule that adds 2 for even whole numbers and subtracts 1 for odd whole numbers gives exactly one output per input, because an input cannot be both even and odd.

## Stretch your reasoning

Reversing a function need not give another function. If 2 and 5 both lead to 7, reversing the arrows makes input 7 lead to both 2 and 5.

Also distinguish a complete relation from a few observations. Three successful machine tests show no conflict in those observations; they do not establish what happens for every untested input. A complete rule can establish that broader claim.
