# Unit 4 Mixed Review

## Connect equations to systems

Unit 4 begins by preserving equality in one equation and ends by finding values that satisfy two equations together. Before calculating, identify whether you need a single variable value, an ordered pair, a solution count, or an explanation of a model.

## Simplify without changing meaning

Solve `3(x + 2) = x + 14` by distributing to get `3x + 6 = x + 14`. Subtract x and 6 to obtain `2x = 8`, then divide by 2. The answer is `x = 4`.

Check in the original equation: `3(4 + 2) = 18` and `4 + 14 = 18`.

For fractions, multiply every term on both sides by a common denominator. For negative factors, distribute the sign to every term inside parentheses.

## Combine two constraints

Solve `x + y = 10` and `2x + 3y = 24`.

Double the first equation and subtract it from the second. The result is `y = 4`. Substitute into the first to get `x = 6`. Verify `2(6) + 3(4) = 24` as well as `6 + 4 = 10`.

## Interpret special outcomes

`2x + 2y = 20` repeats `x + y = 10`, so that system has infinitely many real solutions on one line. Replacing 20 with 22 creates a contradiction and no solution. Cancellation alone does not distinguish those cases; inspect the remaining constants.

## Choose the representation that helps

| Need | Useful action |
| --- | --- |
| Explain a proposed answer | Substitute into original equations |
| Compare two costs | Define the input and equate the costs |
| Find an intersection | Graph to understand, use algebra for exact values |
| Diagnose an error | Locate the first step that changes equality |
| Judge a word-problem answer | Check units and allowed values |

## Finish with reasoning

Ask whether the result fits the situation. A negative time or fractional ticket count can reveal a modeling problem even when the algebra is correct. When explaining a method, name the operation, why it preserves equality, and how the original conditions verify the answer.
