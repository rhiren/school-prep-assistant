# Grade 7 Science Rollout Plan

This plan preserves the Grade 7 Science authoring method for the year. It is
intended to keep the course coherent as we add one concept pack at a time.

## Course Identity

- Subject: Science
- Course: Grade 7 Life Science
- Course id: `course-7-life-science`
- Local pathway: SRVUSD
- Standards framework: CA NGSS

The course follows the SRVUSD / California Grade 7 life-science emphasis while
keeping reproduction-specific instruction teacher-led for now. The app sequence
focuses on cells, body systems, growth, energy flow, ecosystems, genetics,
evolution, and biodiversity / human impact.

## Design Rule

A Science concept is `Practice ready` only when it tests transfer, not just
recall.

Recall asks whether the learner remembers a word or fact. Transfer asks whether
the learner can use the idea when the surface details change. Science practice
should regularly ask the learner to reason from a scenario, model, diagram,
table, data pattern, evidence claim, or cause/effect chain.

## Tutorial Pattern

Each Grade 7 Science tutorial should use a retention-focused learning loop:

1. Hook mystery or phenomenon first
2. Big idea in plain language
3. Learn it in small chunks
4. Build the model, system map, or cause/effect chain
5. Memory anchors the learner can say back later
6. Compare / contrast or evidence rules
7. Common traps and misconception fixes
8. Pause-and-think retrieval prompts
9. Apply-it scenario
10. optional safe at-home investigation
11. 3-2-1 memory check

Keep tutorials concept-specific. Do not clone a generic tutorial body across
concepts with only the heading changed.

### Tutorial Authoring Standard

Science tutorials should help the learner remember, not only understand in the
moment. Favor short sections, repeated memory hooks, and quick retrieval prompts
over long textbook-style exposition.

Each tutorial should include these learner-facing sections:

- `## Hook`
- `## Big Idea`
- `## Learn It`
- `## Build The Model`
- `## Memory Anchors`
- `## Compare And Contrast` or `## Evidence Rules`
- `## Common Traps`
- `## Pause And Think`
- `## Apply It`
- `## Try At Home` when a safe, low-material investigation fits
- `## 3-2-1 Memory Check`

Use the same rhythm across concepts so the learner recognizes the pattern:

- **Learn**: introduce one idea at a time
- **Pause**: ask a no-choice retrieval question
- **Remember**: give a short phrase or anchor
- **Apply**: use the idea in a new scenario
- **Check**: end with 3 things, 2 traps, and 1 explain-it prompt

Good memory anchors are short and reusable:

- `Cells are the evidence.`
- `Structure helps function.`
- `Claims need evidence.`
- `Models show relationships.`
- `Environment changes selection.`

Do not overuse multiple-choice inside tutorials. The tutorial should train the
student to recall and explain before the test provides choices.

## Question Metadata

Science questions should use the existing `skillTags` plus Science-specific
`reasoningTags`.

Supported reasoning tags:

- `recall`
- `scenario-transfer`
- `claim-evidence`
- `model-interpretation`
- `cause-effect`
- `data-pattern`
- `misconception-check`

Use `recall` sparingly. A ready concept pack should not be vocabulary-only.

## Practice-Ready Checklist

Before a Grade 7 Science concept becomes learner-ready:

1. tutorial exists and follows the Science tutorial pattern
2. core test exists
3. review test exists
4. tests include multiple skill tags
5. tests include non-recall reasoning tags
6. tests include at least three Science reasoning forms across core + review
7. multiple-choice answer keys exactly match authored option values
8. scoring validation passes
9. concept has relevant CA NGSS tags
10. concept enters the active manifest as assessable

## Test Shape

Core tests should contain 30 questions for each learner-ready concept. Review
tests should contain at least 15 questions for spaced reinforcement. A smaller
starter pack may be used only while a concept remains `Coming soon`; it should
not be marked learner-ready until the 30-question core practice, review test,
and transfer coverage are in place.

Target mix for a full 30-question core test:

- 20-25% vocabulary or basic concept checks
- 25-30% scenario transfer
- 20-25% claim/evidence or explanation selection
- 15-20% model, diagram, or data interpretation
- 10-15% misconception or challenge reasoning

Target mix for a full review test:

- less isolated vocabulary than the core test
- more scenario transfer
- at least one mixed prior-concept connection when appropriate
- at least one question requiring evidence or model interpretation

## Recommended Build Order

The latest completed enrichment pair is Water Transport and Transpiration,
followed by Investigating Photosynthesis. Each includes 30 core questions,
15 distinct review questions, a worked data model, retrieval prompts, and a
safe home activity. Together they connect plant water balance to carbon dioxide
entry and distinguish transport, photosynthesis, respiration, and net oxygen
change. These are deeper investigations of existing course ideas, not a claim
about the school's current teaching order.

The water pack's MS-LS1-2 tag connects to cell structure/function and turgor;
xylem transport and transpiration are supporting enrichment, not a claim of
complete coverage of that performance expectation. The photosynthesis pack
connects MS-LS1-6 and MS-LS1-7 through matter/energy models and oxygen accounting.
The celery activity requires adult cutting and does not measure exact
transpiration. The paper oxygen-budget activity uses invented data and must
not be presented as a measurement of living plants.

Plant investigation references:
- [NGSS MS-LS1 models and matter/energy processes](https://www.nextgenscience.org/dci-arrangement/ms-ls1-molecules-organisms-structures-and-processes)
- [USGS: evapotranspiration and the water cycle](https://www.usgs.gov/water-science-school/science/evapotranspiration-and-water-cycle)

The preceding completed enrichment pair is Competition and Resource Partitioning,
then Invasive Species and Food-Web Changes. Each has 30 core and 15 distinct
review questions, a worked comparison table, and an optional paper-model
investigation. The pair extends limiting factors, recovery, and biodiversity
design reasoning. It does not establish the school's current teaching order.

Competition questions distinguish shared use from demonstrated limitation and
test alternative explanations for growth differences. Invasion questions
distinguish non-native origin from harm, trace indirect effects, and evaluate
native recovery and non-target impacts alongside target removal.

The October enrichment pair builds on energy pyramids and limiting factors:
Decomposers and Matter Cycling, followed by Ecosystem Disturbance and Recovery.
Each includes 30 core questions, 15 separately authored review questions, worked
data examples, and an optional outdoor observation with explicit limits on
what it can establish. These are course extensions, not a claim about the
school's current teaching order.

For this pair and future packs, use plausible concept-specific distractors,
balanced answer positions without repeating cycles, and distinct review
scenarios. Challenge items should require interpreting evidence or evaluating
an explanation; do not fill banks with generic questions about study habits.
Preserve these requirements in the new-pack regression test as packs are added.
